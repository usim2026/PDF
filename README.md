# PDF 工具

在 Windows 上本地处理 PDF 的桌面程序。打开后的原文件只读：旋转、删除、裁切、改字、拼版和打印都作用在内存里的副本上，结果要另存成新的 PDF，不能覆盖打开时的那个文件。

窗口分三栏：左侧是页面缩略图，中间是预览，右侧是编辑、拼版和打印。默认输出目录是桌面上的「PDF输出」。

## 直接运行

面向已安装 Windows 10 或 Windows 11 的电脑，不需要再安装 Python。

1. 打开 [Releases](https://github.com/usim2026/PDF/releases/tag/v1.0.0)，下载 `PDF工具-Windows.zip`。
2. 把压缩包整个解压到一个文件夹。里面是目录 `PDF工具`，其中有 `PDF工具.exe`，以及同目录下的运行库。
3. 双击 `PDF工具.exe`。

只复制 `PDF工具.exe` 而丢掉旁边的文件时，程序打不开。第一次启动若被安全软件拦截，选择允许；PyInstaller 打包的程序有时会被误报。

从源码启动时，需要 Python 3.12，并已执行 `pip install -r requirements.txt`。在项目目录运行 `python -m app`。`打开PDF工具.vbs` 会调用本机 `%LocalAppData%\Programs\Python\Python312\pythonw.exe`，找不到这个解释器时会提示并退出。

## 打开文件

- **打开**：打开一个或多个 PDF，或把文件拖进窗口。拖进来的如果是文件夹，只收这一层里的 PDF，不含子文件夹。已经开着文件时再打开，会追加到后面。
- **发票打印**：专门导入要记账的发票。只有从这里进来的页面才进入发票汇总，并参加重复检查。用「打开」或拖放进来的 PDF 不计入汇总。
- 对话框里可以多选文件，也可以点「导入此文件夹内全部 PDF」。
- 加密的 PDF 会要求输入密码。
- **清空**：关掉当前全部文档。有未另存的修改时，可以选择先保存、丢弃或取消。
- 带数字签名的文件会在右侧提示。改字会破坏签名；拼版和打印不改原文件。

## 页面

在左侧点选页面，可以多选，也可以拖动缩略图改变顺序。

- **左转 / 右转**：旋转选中的页；没多选时旋转当前页。
- **删除所选**：从副本里删掉选中的页。一次删多页时会先确认。按 Delete 键同样可以删除，输入框里按 Delete 不会误删页面。
- **裁切**：先选「裁切」模式，在预览上拖出一个矩形，再点「应用裁切」。**重置裁切**把这一页恢复成未裁的范围。按 Esc 取消还没应用的矩形。
- **另存为**：把当前副本存成新 PDF。
- **导出所选页**：把左侧选中的页写成一个新 PDF。
- **按页拆分**：每一页各存一个文件，文件名是「原名-页码.pdf」。

## 改字

切换到「改字」，在预览里点中一段文字，改完后点「替换这段文字」。

只替换点中的那一段，不会把后面的文字往后推。新文字比原位置宽时，字号会缩小以尽量放进原框；放不下时会提示溢出。清空输入再替换，等于删掉这一段。没有文字层的扫描页不能改字，程序也不会对它做 OCR。

## 拼到 A4

把选中的页，或全部页面，排到 A4 上。每张纸可以放 1、2 或 4 页，默认 2 页。

- **边距**、**间距**以毫米计，默认 8 mm 和 6 mm。
- **去掉周围空白**：按页面上实际墨迹收紧，而不是把整页空白一并缩进去。
- **画裁切线**：在格子之间画出裁切标记。
- **适应格子**：缩放到格子里。**实际大小**：按原尺寸放置，装不下时会给出警告。
- **拼版预览**里可以在竖版和横版之间切换，再保存或打印。
- **保存拼版 PDF** 直接把拼好的结果另存。拼版是矢量放置，不是先把每一页渲成图片再贴上去。

## 本地打印

选择本机打印机和份数，点「打印拼版」。打印前会说明将要打出多少张 A4，以及是横版还是竖版。页面按实际纸张铺满，不再额外缩小。没有检测到打印机时，先保存拼版 PDF，再用系统打印。

边距、间距、拼版张数、缩放、范围、份数和上次使用的打印机会记在本机，下次打开仍然有效。

## 发票汇总

点「发票汇总」时，只统计通过「发票打印」导入的页面。每一页有文字层的发票整理成一行，表格列为：

页码、发票号码、开票日期、购买方、销售方、金额、税额、价税合计、备注。

相同发票号码只保留一行，重复的号码不计入金额合计，对话框里会列出已跳过的号码。没有识别出金额的行会说明未计入。项目明细不拆成多行。确认后可导出 `.xlsx`，默认文件名是桌面「PDF输出」里的「发票汇总.xlsx」。

识别依赖 PDF 里的文字，例如「发票号码」「开票日期」「名称」和价税合计。扫描件或文字被转成轮廓的发票读不出这些字段。

## 从源码打包

`PDF工具.spec` 用 PyInstaller 打成目录模式，入口是 `launch.py`。在 Windows 上安装依赖和 PyInstaller 后，于项目目录执行：

```bat
pyinstaller --noconfirm --clean PDF工具.spec
```

生成的程序在 `dist\PDF工具\PDF工具.exe`。推送到 `main` 且改动了程序、依赖或打包脚本时，GitHub Actions 会在 Windows 上重新打包，并更新 [v1.0.0](https://github.com/usim2026/PDF/releases/tag/v1.0.0) 附件里的 `PDF工具-Windows.zip`。
